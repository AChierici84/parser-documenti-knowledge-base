# File Markdown di Prova

Benvenuto nel tuo file Markdown di prova generato automaticamente! Il formato **Markdown** è un linguaggio di markup leggero con sintassi di formattazione in testo puro.

## Elementi Comuni

### 1. Elenchi puntati e numerati
Ecco come appare un elenco puntato:
* Primo elemento importante
* Secondo elemento di dettaglio
* Terzo elemento conclusivo

E un elenco numerato:
1. Effettua l'accesso
2. Carica il documento
3. Visualizza il risultato

### 2. Blocchi di Codice
Puoi inserire facilmente frammenti di codice con la formattazione corretta:

```python
def saluta(nome):
    print(f"Ciao, {nome}! Questo è un file .md di prova.")

saluta("Utente")
```
